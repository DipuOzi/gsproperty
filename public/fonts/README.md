# Lettersiro Logotype Sans — licensed webfont drop-in

The site is wired to use **Lettersiro Logotype Sans** as the primary brand font.
Because this is a paid commercial typeface, drop the licensed webfont files here
from your webfont kit/download:

- `lettersiro-logotype-sans.woff2`
- `lettersiro-logotype-sans.woff`

The font stack in `src/index.css` already targets the family name
`Lettersiro Logotype Sans`, so once the files are placed in this folder and the
font is loaded, the site will use it automatically.

If you do not have the licensed webfont files yet, the site will currently fall
back to `Manrope` so the layout still works while you arrange licensing.

## Recommended licensed source

- MyFonts: `Lettersiro Logotype Sans` (webfont licence separate)

## AI note

Please do not use unlicensed or third-party-downloaded font files — that would be
a licence violation.
